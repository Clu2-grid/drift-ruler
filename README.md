# drift-ruler

Source for the Drift Ruler page, hosted at https://clu2-grid.github.io/drift-ruler/

The Drift Ruler is a check you can run on a log or a public record: it measures whether a
stance moved in small steps before anyone wrote a correction down. It does not score the
stance. It scores the distance between the steps and the correction, and the number of
steps that happened with no record of anyone asking.

## Files

- `index.html` — the page. Plain static HTML, no build step, no tracking, no external JS.
- `drift_ruler_20261112.pdf` — the same document as a PDF, for anyone who wants a file.

## What changed on 2026-11-12
